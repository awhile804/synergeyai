## 2024-05-24 - Accessible Expand/Collapse Buttons in Clickable Wrappers
**Learning:** When adding expand/collapse buttons inside a parent wrapper that is also clickable (e.g. an accordion header), you cannot rely purely on the wrapper's `onclick`. Screen readers and keyboard users require a distinct, semantic `<button>` inside the wrapper with `aria-expanded` and `aria-controls`. However, clicking this inner button will bubble up and trigger the wrapper's `onclick`, often causing the state to toggle twice.
**Action:** When creating semantic inner expand buttons in clickable rows, always add `event.stopPropagation()` to the inner button's `onclick` handler. Ensure the JS toggle function updates the `aria-expanded` attribute on the button dynamically (both setting it to true on expansion and false on collapse, remembering to reset it for previously expanded siblings).
