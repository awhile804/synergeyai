## 2024-05-15 - Dynamic Token Visibility Toggles and Privacy Preservation
**Learning:** Hardcoded "Show" text on password/token toggles leads to an inconsistent state if users click the toggle (displaying plain text) and the button still reads "Show". Additionally, if the modal containing these tokens is closed while the token is visible, reopening the modal exposes the token, compromising privacy.
**Action:** Always dynamically update the text of visibility toggles to accurately reflect the input state ("Show" / "Hide") by passing `this` via the inline `onclick` handler. Furthermore, always reset the input state to `type="password"` and the toggle text to "Show" when a modal is opened to maintain privacy and a consistent user experience. Ensure `type="button"` is set to prevent form submissions.
