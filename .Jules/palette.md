## 2024-04-10 - Expanding Row Accessibility
**Learning:** Across the different dashboards (index, sprint-planner, transcript-analyzer), there is a recurring pattern of expandable lists or rows where the toggle element is missing `aria-expanded` and `aria-controls`. Moreover, some "expand" icons are wrapped only in `span` elements within larger clickable areas instead of focusable `button` elements, preventing keyboard access.
**Action:** When implementing or fixing expanding sections, always ensure the dedicated toggle is an actual `<button>` with `aria-controls` pointing to the content ID and dynamically update its `aria-expanded` state via JavaScript. If a wrapper needs to be clickable for pointer users, keep the `onclick` on the wrapper but use `event.stopPropagation()` on the inner accessible button.
