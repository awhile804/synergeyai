## 2024-03-12 - Missing explicit labels in .form-group containers
**Learning:** The `<div class="form-group">` component pattern extensively used in this application historically omitted explicit `for` attributes on its `<label>` children. While visually adjacent to inputs, this structure is completely disconnected for screen readers because the `<label>` doesn't automatically wrap the `<input>` (implicit binding) and lacks the `for="..."` ID reference (explicit binding). This breaks forms for keyboard users (can't click label to focus input) and screen readers (no announced name).
**Action:** Whenever reviewing or creating new forms using the `.form-group` pattern, ALWAYS explicitly verify that the `<label>` has a `for` attribute that precisely matches the `id` of the target form control (`<input>`, `<select>`, `<textarea>`).
