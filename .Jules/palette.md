## 2024-05-18 - Accessible Toggle Buttons and Click Wrappers
**Learning:** When adding `aria-expanded` and semantic toggle interactions to items inside a clickable wrapper (e.g. `onclick` on an entire row or header container), it is crucial to place `onclick="event.stopPropagation(); ..."` on the inner semantic button. This allows keyboard/screen reader users to trigger the specific action (like expanding a section) with proper ARIA state updates without inadvertently firing the wrapper's click event. Additionally, keeping `aria-expanded` and `aria-controls` explicitly in sync via JS ensures screen readers correctly interpret the dynamic state changes.
**Action:** Always verify if a native `<button>` element is nested within another clickable element. When adding semantic expand/collapse attributes, bind the `aria-*` attributes and state-toggling logic to the `<button>` itself and stop event propagation so pointer and keyboard users get the intended isolated behavior.
